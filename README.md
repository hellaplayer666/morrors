RoadMirror

iOS-прототип для исследования возможности вывода изображения iPhone на экран Omoda C5 (2023) через Apple CarPlay.

Цель проекта

Проверить техническую возможность отображения изображения iPhone на автомобильном дисплее с адаптацией под формат экрана.

Важные ограничения

* Обычные приложения iOS не имеют универсального API для полного зеркалирования экрана в CarPlay.
* ReplayKit сам по себе не обеспечивает передачу изображения в CarPlay.
* Некоторые функции CarPlay требуют отдельного разрешения Apple.
* На текущем этапе это исследовательский проект, а не готовое приложение для зеркалирования.

План разработки

1. Подготовить структуру iOS-проекта.
2. Настроить сборку через GitHub Actions.
3. Проверить доступность CarPlay и необходимые разрешения.
4. Исследовать технически реализуемый способ передачи изображения.

Сборка

Сборка для симулятора не означает, что приложение можно установить на iPhone или использовать в автомобиле. Для установки на устройство потребуются подпись приложения и профиль разработчика.
